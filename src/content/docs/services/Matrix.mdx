## Matrix

Calculate travel cost between multiple points.

- Method: `POST`
- Path: `/services/matrix`
- Required allowed service: `MATRIX`
- Billed service: `MATRIX`

## Request body

```json
{
  "sources": [{ "lat": 8.9806, "lon": 38.7578 }],
  "targets": [
    { "lat": 8.99, "lon": 38.76 },
    { "lat": 9.01, "lon": 38.78 }
  ],
  "costing": "AUTO"
}
```

## Rules

- `sources` max `50`.
- `targets` max `50`.
- Only one-to-many or many-to-one is allowed.
