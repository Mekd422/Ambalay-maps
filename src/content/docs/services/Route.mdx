## Route

Calculate a route between a source and destination.

- Method: `POST`
- Path: `/services/route`
- Required allowed service: `ROUTING`
- Billed service: `ROUTING`

## Request body

```json
{
  "source": { "lat": 8.9806, "lon": 38.7578 },
  "destination": { "lat": 8.99, "lon": 38.76 },
  "via": [],
  "costing": "AUTO"
}
```

## Rules

- `via` can contain at most `10` points.
- Supported `costing`: `AUTO`, `PEDESTRIAN`, `BICYCLE`, `TRUCK`.

  "data": {
